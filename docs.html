Обзор

Что такое QuadAI и из чего он состоит

QuadAI — это ИИ-ассистент от QuadLegacy. Он отвечает текстом, а ещё умеет превращать ответ в короткое 3D-видео (режим FluxV-Tempo). Пользоваться им можно тремя способами:

Telegram-бот@quadlegacyshizoaibot

Основной способ. Чат, видео-ответы, группы, Telegram Business.

Веб-чатindex.html

Тот же ассистент в браузере или WebView, с историей чатов и темами.

HTTP API:8089

Ключ qla_… и запросы из своих скриптов и приложений.

Beta-бот@qwenaibot

Тестовая версия, где первыми появляются новые функции.

Быстрый старт

От нуля до первого ответа за минуту

Через Telegram

  1. Открой бота @quadlegacyshizoaibot и нажми Start.
  2. Напиши любое сообщение, и бот ответит выбранной моделью.
  3. Чтобы получить видео-ответ, начни сообщение с /video.

Через веб-чат

  1. Открой страницу чата и нажми на аккаунт в левом нижнем углу.
  2. Выбери BETA или PROD, нажми Start в открывшемся боте. Аккаунт привяжется автоматически.
  3. Либо вставь API-ключ qla_… (в боте: 🔌 API).
  4. Выбери модель в шапке и пиши сообщение.
💡 Совет Привязка через Telegram и API-ключ — разные способы входа. Можно привязать оба и переключаться между аккаунтами в меню аккаунта.

Telegram Business

QuadAI можно подключить к личному профилю через Telegram Business: бот сам отвечает на входящие сообщения выбранной моделью и вашим системным промптом. Пошаговая инструкция — на странице подключения.

Веб-чат

Интерфейс в браузере и WebView

  • Чаты. Список слева, у каждого чата кнопка удаления. На телефоне панель открывается кнопкой меню или свайпом от левого края.
  • Модель. Кнопка с названием в шапке или значок настроек. Буква-аватар в сообщениях совпадает с первой буквой модели.
  • Аккаунты. Можно держать несколько аккаунтов (Telegram и API-ключи) и переключаться между ними.
  • Ответы. Потоковый вывод, блоки кода с кнопкой «Копировать», ход мыслей (Qwen) и статистика скорости.
  • Ввод. На компьютере Enter отправляет, Shift+Enter — новая строка. На телефоне Enter даёт новую строку, отправка — кнопкой.

HTTP API

Все запросы и ответы — JSON

Базовый адрес — адрес вашего сервера QuadAI (в примерах https://ai.quadlegacy.cyou), сервис слушает порт 8089. Все пути начинаются с /api/v1.

Авторизация

Передай один из двух заголовков:

ЗаголовокЗначение
AuthorizationBearer qla_… — API-ключ из бота (🔌 API)
X-TG-TokenТокен сессии, выданный при привязке через Telegram
⚠️ Храни ключ в секрете Ключ qla_… даёт доступ к вашим лимитам и чатам. Не публикуй его в репозиториях и не вставляй в клиентский код.

POST/api/v1/chat

Ставит запрос в очередь и возвращает задачу.

ПолеТипОписание
modelstringfluxt_gidrod, qwen25, gemini или fluxv_tempo
messagestringТекст сообщения
chat_idnumberНеобязательно. Чат, в который писать (иначе активный)
waitbooleanfalse — сразу вернуть job_id и опрашивать самому. true — дождаться ответа в этом запросе
curl
curl -X POST https://ai.quadlegacy.cyou/api/v1/chat \
  -H "Authorization: Bearer qla_ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini","message":"Привет!","wait":false}'
ответ
{
  "job_id": "abc123",
  "status": "queued",
  "queue_ahead": 0
}

GET/api/v1/jobs/{job_id}?wait=0.4

Возвращает состояние задачи. Параметр wait — сколько секунд сервер может подержать запрос, ожидая изменений (long polling).

ПолеОписание
statusqueued — в очереди, running — идёт генерация, error — ошибка, иначе готово
queue_aheadСколько задач впереди (при queued)
stage, stage_detail, stage_elapsedТекущий этап, пояснение и сколько секунд он идёт
steps_doneЗавершённые этапы: [{label, seconds}]
partial_text, partial_thoughtsУже сгенерированная часть ответа и мыслей (потоковый вывод)
textИтоговый ответ
thoughtsХод мыслей (Qwen)
stats, stats_textСтатистика: total, gen_speed, gen_tokens, ttft, render_fps, compute_ms и текстовая сводка
file_urlПуть к видео (для fluxv_tempo). Скачивается с теми же заголовками авторизации
timeouttrue, если время генерации вышло и ответ неполный
errorТекст ошибки при status: "error"
Python — отправка и ожидание
import time, requests

BASE = "https://ai.quadlegacy.cyou/api/v1"
H = {"Authorization": "Bearer qla_ВАШ_КЛЮЧ"}

job = requests.post(f"{BASE}/chat", headers=H,
                    json={"model": "gemini", "message": "Объясни Raycasting", "wait": False}).json()

while job["status"] in ("queued", "running"):
    time.sleep(0.5)
    job = requests.get(f"{BASE}/jobs/{job['job_id']}?wait=0.4", headers=H).json()

if job["status"] == "error":
    print("Ошибка:", job["error"])
else:
    print(job["text"])

Привязка Telegram

Нужна, чтобы получить токен сессии без API-ключа (так работает веб-чат).

  1. POST/tg/link/start без авторизации. Ответ: {code, bots: {beta, prod}}, где bots — ссылки на ботов.
  2. Открой нужную ссылку, пользователь нажимает Start в боте.
  3. Опрашивай GET/tg/link/poll?code=… раз в 1–2 секунды (код живёт 5 минут), пока status не станет done.
  4. В ответе придут tg_token, user_id, full_name, username, avatar_url и bot_kind. tg_token дальше передаётся в заголовке X-TG-Token.

Этапы и статистика

Что видно, пока ответ генерируется

Пока задача в статусе running, в ответе /jobs приходит текущий этап, а завершённые копятся в steps_done. Примеры этапов:

МодельЭтапы
FluxV-Tempo«Делаю сценарий…», «Рендерю…»
Geminiподключение к DeepMind API, генерация, получение частей через API
FluxT-GidroD«Делаю ответ смешным»
Qwen 2.5«Думаю…»

После ответа доступна статистика: общее время, скорость в токенах в секунду (с «~», если число токенов оценочное), число токенов, время до первого токена, для видео — кадры в секунду рендера.

При первом запуске сайт сам выбирает стиль по версии Android и запоминает его. Дальше выбор остаётся за пользователем.

Версия берётся из User-Agent, либо из параметра ?api=, если передать в ссылке номер SDK:

Ссылки на Telegram Чтобы t.me открывался в приложении Telegram, а не внутри WebView, перехватывай такие ссылки в onPageStarted и отдавай их системе через Intent.ACTION_VIEW. А для кнопки «Назад» добавь в onBackPressed проверку webview1.canGoBack().

FAQ

Частые вопросы и ошибки

Проверь, что ключ начинается с qla_ и скопирован целиком. Если вход был через Telegram, привяжи аккаунт заново: токен сессии мог устареть.

Сервер недоступен или не запущен. Если адрес указан в REMOTE_API (для хостинга на github.io), проверь, что он верный и что туннель работает.

Модель не успела закончить, и вернулась уже готовая часть (timeout: true). Для долгих ответов выбери более быструю модель или разбей вопрос на части.

Включи setDomStorageEnabled(true), иначе WebView не хранит данные страницы между запусками.

WebView не умеет открывать tg: и intent:. Перехвати такие ссылки в приложении и открой их через Intent.ACTION_VIEW.

В боте — командой /clear. В веб-чате — кнопкой удаления у нужного чата в списке слева (DELETE /chats/{id} в API).
